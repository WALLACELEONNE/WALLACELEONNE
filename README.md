## Sobre

Sou sócio-fundador, consultor e executante da **APOC Tecnologia**: converso com o cliente, desenho a solução, escrevo o código e coloco em produção. Trabalho com escopo fechado, prazo e preço definidos por escrito antes do contrato, e com entrega incremental: cada fatia vai a produção e é validada antes da próxima.

Minha base é **dados**. Antes da APOC, passei quase cinco anos no agronegócio dentro da implantação de um SAP S/4HANA RISE (projeto greenfield): migração de dados via SAP Data Migration Cockpit, ETL em Python, regras de negócio entre o ERP legado e o SAP, dashboards em Power BI e consultas SQL em Oracle, SQL Server e PostgreSQL. Hoje levo essa visão de processo e de dado para sistemas sob medida, integrações e automação com IA.
